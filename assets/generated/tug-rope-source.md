# Tug of War rope artwork

- **Source:** `tug-rope-source.jpg`, generated with the Cloudflare Workers AI image MCP on 2026-10-22.
- **Model:** `@cf/black-forest-labs/flux-1-schnell`, 8 steps.
- **Art direction:** One straight, uniformly thick horizontal brown braided rope, dark outline, warm fiber highlights, isolated on magenta for background removal.
- **Runtime asset:** `games/Tug Of war/assets/rope-uniform.png`. An interior section of the generated braid was chroma-keyed, reduced to a 32 × 8 pixel tile, and mapped to a six-color warm pixel-art palette. The silhouette and tile seam were normalized for a continuous 24-pixel-wide `Line2D`.
- **Character integration:** `p1-puller.png` through `p4-puller.png` are derived from the corresponding `pN.png` character atlases. Only the baked-in rope pixels beyond each character's hand outlines were removed. The source atlases are retained. P2's looping idle artwork comes from `assets/orange p2 revised/tugging animationorangeidle.png`, copied into `p2.png`.
- **Pull effects:** `p1-pull-effect.png` through `p4-pull-effect.png` are derived from the corresponding `pN effect.png` atlases. P2's key-triggered pull artwork comes from `assets/orange p2 revised/tugging animationorange.png`, copied into `p2 effect.png`; it plays once per pull-key press, then returns to the separate idle sheet. The baked-in rope pixels beyond the hand outlines were removed: local columns 22–31, rows 18–20 in high-grip poses, and columns 21–31, rows 19–21 in lower-grip poses. Frame zero uses the high grip for all players; revised P2 also uses it in frame three and its recovery frame. P2–P4 have four source frames, so their last rope-free idle pose is appended to match P1's fifth recovery frame and keep effect timing consistent. Idle and effect animations share a single sprite and grip alignment so only the continuous `Line2D` supplies the rope in either state.
